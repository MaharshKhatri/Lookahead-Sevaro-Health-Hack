# Requirements traceability: Sevaro Challenge 2 brief

Maps every requirement in `docs/brief_c2.md` to the code that implements it, the UI where a judge sees it, the tests that assert it, and a status. Built by reading the source and the tests (`describe`/`it` names are quoted verbatim); nothing here was inferred from docs alone. Policy choices behind each row are in `docs/OPEN_QUESTIONS.md` (OQ-nn) and `docs/DECISIONS.md` (D-nn).

Path prefixes: `E/` = `packages/engine/src`, `ET/` = `packages/engine/test`, `W/` = `apps/web/src`, `WT/` = `apps/web/test`, `E2E/` = `apps/web/e2e`. Other paths are repository-relative. "Reference data at 18:20" means `data/raw` replayed at 18:20:00 ET (`snapshotAsOfMs`). Test names built by a loop or `it.each` are quoted as they render (for example `ET/roles.test.ts`: "approveOffer by coordinator: FORBIDDEN_ROLE", from the every-command x every-role loop).

Status: **Covered** = implemented, visible in the UI (or engine-only by nature), and asserted by a test. **Partial** = implemented but missing a UI surface, an audit path, or a direct test. **Gap** = not implemented.

Refreshed 2026-10-11 (final build) against the current code and tests; rows that cite files still uncommitted at refresh time say "uncommitted".

Totals: 96 rows: 94 Covered, 1 Partial, 1 Gap (§1-§7, the brief: 85 rows, 83 Covered, 1 Partial, 1 Gap; §8, extensions: 11 rows, 11 Covered). Gaps and partials are listed with fixes at the end.
